# Auth / Login Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement a full-screen Login page for LearnXpert LnD, backed by a mock auth datasource, navigating to a static Dashboard on success.

**Architecture:** Feature `auth` follows Clean Architecture (domain → data → presentation). `MockAuthRemoteDataSource` replaces the generated Retrofit datasource (no BE yet). Feature `dashboard` is presentation-only static. `LoginNotifier` is `AsyncNotifier<void>` — the page listens to state and navigates on `AsyncData`.

**Tech Stack:** Flutter, Riverpod (codegen), GoRouter, fpdart Either, Freezed, ScreenUtil, melos

@riverpod
class LoginNotifier extends _$LoginNotifier {
  @override
  FutureOr<void> build() {}

  Future<void> login({
    required String email,
    required String password,
  }) async {
    state = const AsyncLoading();
    final result = await ref
        .read(authRepositoryProvider)
        .login(email: email, password: password);
    result.fold(
      (failure) =>
          state = AsyncError(failure.readableMessage, StackTrace.current),
      (_) => state = const AsyncData(null),
    );
  }
}
